# Глоток

Трекер воды для Леры. Питомец (выдра, ласка, такса или кошка) радуется, когда она пьёт, и жалуется на головную боль, когда забывает.

## Что где

- `web/` — само приложение (PWA). Лежит на GitHub Pages: https://zxcloxg.github.io/glotok/
- `web/admin.html` — страница, где пишутся письма на каждый день и можно отправить напоминание вручную.
- `worker/` — сервер на Cloudflare Workers. Раз в 10 минут проверяет, когда Лера пила в последний раз, и шлёт уведомления. Хранит данные и письма в KV.
- `scripts/gen-keys.mjs` — создаёт ключи в `secrets.local.json` (в git не попадает, не теряй его).
- `scripts/make-icons.mjs` — рисует иконки.

## Как работают напоминания

Интервал настраивается в приложении (по умолчанию 1,5 ч).

| Сколько не пила | Что происходит |
|---|---|
| 1 интервал | питомец хочет пить, первое уведомление |
| 1,75 интервала | болит голова, второе уведомление |
| 2,5 интервала | всё очень плохо, дальше повторяется раз в интервал (не больше 3 раз) |

Ночью (по умолчанию 00:00–08:00) уведомлений нет. Утром, если она ещё не пила, приходит «доброе утро». После выполнения нормы напоминаний нет.

## Обновить приложение

Правишь файлы в `web/` и делаешь `git push`. Через минуту новая версия на телефоне.

## Обновить сервер

```
cd worker
npx wrangler deploy
```

## Требования к iPhone

iOS 16.4 или новее. Приложение нужно добавить через Safari → «Поделиться» → «На экран „Домой“» и открывать оттуда. Иначе iOS не даёт присылать уведомления.
